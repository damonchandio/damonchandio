### 🧰 Open source

Small tools that came out of running my own AI agents every day. Each one fixes one real problem.

| Project | What it does | Stack |
| --- | --- | --- |
| [**free-llm-router**](https://github.com/damonchandio/free-llm-router) | Run agents on free LLM tiers (Groq, Gemini) with a local fallback. Rests a provider when it hits a rate limit, and keeps private requests away from free tiers that may train on them. | Python |
| [**seo-agent-team**](https://github.com/damonchandio/seo-agent-team) | Six agents that keep a WordPress site growing: keyword research, sourced articles, a Rank Math 95+ gate, Bing and Google indexing, rank tracking and rewrites. | Python · WordPress |
| [**email-scanner-detector**](https://github.com/damonchandio/email-scanner-detector) | Email security scanners click your links within seconds and fake opens and unsubscribes. In my own outreach, all 11 opt-outs were scanners. This spots them. | JavaScript · zero deps |
| [**outreach-agents**](https://github.com/damonchandio/outreach-agents) | Personalised B2B outreach agents: find companies, build each a demo from its own site, write, and send safely with caps and opt-outs. | Python · SQLite |
