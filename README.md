### What I work on

**Retrieval that cites its sources.** Chunking, embeddings, vector search, and answers that link back to the paragraph they came from, including the part where the system says it doesn't know.

**AI-powered progressive web apps.** Installable from the browser, work on a bad signal, no app store.

**Hardware, occasionally.** Voice interfaces on a Raspberry Pi, built in the open.
